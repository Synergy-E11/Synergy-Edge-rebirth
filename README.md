# Synergy Edge Tech website

A static, responsive HTML/CSS/JavaScript website for Synergy Edge Tech.

## Files
- `index.html` — Home
- `services.html` — Services
- `portfolio.html` — Work and project concepts
- `about.html` — About
- `process.html` — Working process
- `pricing.html` — Pricing approach
- `testimonials.html` — Client experience and testimonial submission link
- `contact.html` — Contact
- `booking.html` — Booking enquiry
- `styles.css`, `script.js`, and `assets/` — styling, interactions, and visuals

## Before publishing
1. Confirm the contact email shown on the site is active and belongs to you.
2. Check all contact links and project details.
3. The testimonials page presents service standards and invites past clients to submit feedback. Add direct client quotes only after receiving their approval.
4. Project concept visuals should remain identified as concepts where relevant; do not imply unverified results or client outcomes.

## Deploy
Extract the ZIP and upload the website files and `assets` folder to Netlify. The site uses plain HTML, CSS, and JavaScript; no build command is required. Test the deployed site on mobile and desktop before connecting a custom domain.
